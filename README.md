# 드래곤 카드 배틀 시즌2

실물 카드의 QR코드로 드래곤을 소환하고, 스프라이트 애니메이션으로 싸우는 태블릿용 웹 게임입니다.
빌드 과정 없는 정적 사이트라서 GitHub Pages 등에 그대로 올리면 됩니다.

## 실행

`start.bat` 더블클릭 → 브라우저에서 http://localhost:5700 이 열립니다.

```bash
python -m http.server 5700
```

카메라(QR 스캔)는 `http://localhost` 또는 `https://` 주소에서만 동작합니다.

## 설정 메뉴 (비밀번호 9466)

- **드래곤 카드**: 이름·등급·공격·방어·체력·이동력, 카드 이미지, 소환 인트로 영상, QR, 동작 스프라이트 4종, 특수능력
- **마법 카드**: 이름·등급(등급별 시전 비용), 이미지, 인트로 영상, QR, 효과
- **재생·비용**: 모든 캐릭터 공통 스프라이트 재생 속도, 등급별 소환/마법 비용, 등급별 기본 이동력
- **배포**: ZIP 내보내기, content.json 가져오기, 배포본으로 되돌리기

설정에서 수정한 내용은 **그 기기(브라우저)에만** 저장됩니다. 다른 태블릿에 반영하려면 아래 "업데이트 방법"을 따르세요.

### 스프라이트 시트 규격

| 동작 | 프레임 | 없을 때 |
|---|---|---|
| 대기 | 4 | 카드 이미지를 움직여 대체 |
| 공격 | 8 | 카드 이미지를 움직여 대체 |
| 피격 | 6 | 카드 이미지를 흔들어 대체 |
| 특수능력 | 8 | 기본 캐릭터 금빛 효과 |

- PNG 권장 (투명 배경이 가장 좋음). 흰색/검은색 배경은 설정에서 "배경 제거"를 고르면 테두리부터 지워 줍니다.
- 캐릭터는 **왼쪽을 보도록** 제작합니다. 게임이 공격/피격 방향에 맞춰 자동으로 반전합니다.
- 한 줄이든 여러 줄 격자든 상관없습니다. 업로드하면 격자(가로 칸 × 세로 줄)를 자동으로 추정하고, 틀리면 직접 고칠 수 있습니다.
- 동작마다 캐릭터 크기가 다르면 "크기"·"세로 위치" 슬라이더로 맞춥니다.

### QR 코드

- 드래곤: `DCB1:카드id` (시즌1 실물 카드 QR 그대로 사용 가능)
- 마법: `DCB2:M:마법id`

## 업데이트 방법 (웹 배포)

1. 관리용 태블릿/PC 에서 설정 → 카드·스프라이트 수정
2. 설정 → **배포** → **ZIP 내보내기**
3. ZIP 을 이 폴더에 풀어서 덮어쓰기 (`assets/content/...`, `js/content-data.js` 가 갱신됨)
4. GitHub 에 커밋·푸시 → GitHub Pages 가 자동 반영
5. 관리 기기는 설정 → 배포 → "배포본으로 되돌리기"로 로컬 편집본을 정리

`content.json` 을 직접 고쳤다면 `python tools/sync-content.py` 로 `js/content-data.js` 도 맞춰 주세요.

## 게임 규칙 요약

- 보드 7×4 육각, 홀수 열이 반 칸 아래. 공격은 바로 옆 칸만.
- 광산 5개: 본진 2(1P 왼쪽 끝·2P 오른쪽 끝, 위에서 2번째 행) + 가운데 열 1 + 좌우 대칭 1쌍(무작위)
- 마나: 시작 1, 최대 10. 턴 시작 시 보유 광산 수만큼 충전.
- 소환: 턴당 1장, 필드 최대 5기, 같은 드래곤·마법은 한 경기에 1번만. 소환한 턴에는 행동 불가.
- 행동: 유닛을 누르면 원형 버튼 4개(이동·공격·특수·종료). 턴마다 이동 1번 + 공격 또는 특수능력 1번, 순서 자유.
- 데미지 = max(10, 내림(공격 − 방어 ÷ 2)), 치명타 10% (공격 1.5배), 반격 없음.
- 특수능력/마법 효과: 체력은 즉시(최대 체력 초과 불가), 공격·방어·이동력은 지속 턴 동안 유지(최소 0).
  효과 턴 수와 쿨타임은 해당 플레이어의 다음 턴 시작 때 1씩 줄어듭니다.
- 승리: 광산 5개 모두 점령 또는 적 7기 격파.
